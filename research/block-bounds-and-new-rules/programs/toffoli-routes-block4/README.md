# Routes for one array in the widened game

**What it shows.** A route is a shortest way to finish one array alone. Counting first backward steps from the
finished transform by orbits of the affine group, `census.py` finds that one array at block 4 has 736,785 routes in
the widened game (30,465 of the 2,027,025 first steps continue), against 315 in the engine game; at block 3, 105
against 21. `example_m3.py` builds one non-affine route at block 3 exactly; `routeshape.py`, `states.py` and
`routegroups.py` study the shapes of the middle states and the groups generated by routes (they read
`census_mM.json`, which `census.py` writes in the current folder).

**Commands** (numpy): `python3 -I census.py 3` (seconds), `python3 -I census.py 4` (under a minute), then
`python3 -I routeshape.py 4`, `python3 -I states.py 4`. `skeptic/sk_census.py` and `skeptic/sk_fredkin.py` are the
skeptic's independent model.

**Expected output.** `CONTINUING first steps: 30465 of 2027025; translation ones: 15; total routes (chains of cosets)
= 736785` at block 4. Original outputs in `../../data/toffoli-routes-block4/`.

**Re-run for this revision:** yes, on 19 October 2026: `census.py 3` and `census.py 4` gave 105 and 736,785 routes
(30,465 of 2,027,025 first steps continue) in 1 and 43 seconds
(`../../data/toffoli-routes-block4/rerun_2026-10-19.txt`). The other route programs and the skeptic's were not re-run.
