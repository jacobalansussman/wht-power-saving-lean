# The ladder above Theorem R

**What it shows.** Checks behind the ladder track: support facts used by the depth bound W + m - 1, the block-2
group computation, the table of units closed by the depth bound, and the growth ratios of two and three moves in a
row (c2/c1 and c3/c1) for the hook and for two-factor certificates, including Λ² ⊗ Λ³ (c2 = 1.848 c1, c3 = 2.515 c1).

**Programs** (pure Python unless noted): `ladder_check.py` (about a minute), `hook_c2.py` and `venn_c2.py` (numpy; a
few seconds and about a minute), `spheres.py`, `playtest_rf.py`. Run each as `python3 -I NAME.py`. Original outputs in
`../../data/ladder-above-theorem-R/`.

**Re-run for this revision:** no.
