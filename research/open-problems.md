## [Speed-first waves 11-15: real processors and FPGAs (11-13 October)](speed-waves/README.md)

|---|---|---|---|
| 1 | Why does the SEAL port gain so much less on a non-Apple Arm core? |  | Time the new kernel and SEAL's lazy forward NTT level by level on a Neoverse N2 (GitHub Arm runners) and try -mcpu=neoverse-n2; if the lazy transform cannot gain, use the new code there only for the fully reduced transforms. |
| 2 | Does the fp64-FMA NTT give the same gain inside OpenFHE? |  | Route OpenFHE's NTT for primes below 2^50 through the floating-point method, run OpenFHE's unit tests, time its own CKKS benchmarks on the M4 and an Arm server runner. |
| 3 | A NEON build of FFTW for conda-forge and Homebrew users. |  | Rebuild conda-forge's recipe with --enable-neon in both precisions and the aarch64 host triple, run FFTW's tests/check.pl, time the probe grid and pyFFTW with the library swapped in. |
| 4 | Does the packed filter bank close timing in AMD's tools? |  | Place and route one lane and one slice in Vivado at 200-250 MHz; compare with AMD's FIR Compiler. |
| 5 | Do Lattice's own tools already fold multiplexers into carry cells? |  | Synthesise the folded and gated generic FFTs with Lattice Radiant on CrossLink-NX; if Radiant folds them, the gain is gone. |
| 6 | Does the convolve kernel survive a critic, and can it be made multi-process safe? |  | Have a critic rebuild the baselines; add a C FFT overlap-save above about 450 taps and the per-cluster try-lock; time 1, 4 and 8 Python processes. |
| 7 | What does the M4's second (efficiency-cluster) matrix unit add? |  | Time the batched complex128 FFT on the E-cluster unit alone, then one P-cluster plus one E-cluster thread plus NEON threads against all-NEON on all ten cores. |

| 9 | Is pocketfft's batched vector path fixable for large rows? |  | Cap the batched buffer at the L1 size and time 64 x 4,096 complex128 again. |
| 10 | What do the small-FPGA designs cost in power? |  | A switching-activity estimate with the open flow for the folded UP5K FFT and its rivals, then one board measurement. |
| 11 | Can HEVC fractional motion estimation route on an ECP5-85F at a usable clock with the encoder's own SATD? |  | Pipeline the candidate-index path and the vertical filters (a cycle-exact latency-neutral split exists), then route with 5 seeds. |
| 12 | How much area does packing two real radar channels per FFT save? |  | Place and route the packed and unpacked chains with 5 seeds each and write the area table. |
