## P1. Every scalar a RAM program computes lies in the field generated by the supplied root [proved, Lean]

**Statement.** Let K be any subfield of C and V any K-submodule of C. Call a value *good* if every component of paint
`scalar` lies in K and every component of paint `left` lies in V (integers, `right`, `both` unconstrained; pairs and
arrays componentwise). Then every program, run on a good input (and, inside a recursion, with a good handler), returns a
good value.

**Lean.** `lean/ExLegitClosure.lean` = OpenAI's file verbatim + 252 lines (`closure-part.lean`). Theorems
`OAI.PowerSaving.RAM.ExLegit.run_good` (all codes, all ports), `prog_good`, `dft_output_mem`, `zeta_mem_of_DFTProgram`.
Elaborated with `lake env lean` in Shea's tree 5239484 on Colab #2: rc 0, 13 s, 6.8 GB; the only `sorry`s are OpenAI's two
open challenge theorems (lines 326, 330), which nothing here uses; axioms of all three printed theorems:
`[propext, Classical.choice, Quot.sound]` (`logs/closure-4.log`).

**Proof (what the Lean does).** Structural induction on `Code`. Atoms: `cz`, `cone` give 0, 1; `add`, `sub` keep a
paint and K, V are closed under them; `scale` multiplies a `scalar` (in K) into a value of paint t: in K for t = scalar,
in V (K-scalar multiple) for t = left; `inv` acts on scalars only and K is closed under inverses (Lean's 0⁻¹ = 0 is in K);
`cross` produces paint `both` (unconstrained, and only when `allow = true`); `look` returns an array entry or the blank
(0, which is good); `lit`, `int`, `len` produce integers. `comp`, `fork`, `ifz`: immediate. `loop`: induction on the
number of steps (`Bill.steps`). `tab`, `sow`: the array starts as blanks and each `Tape.set` writes a good value.
`importClosed`, `call`: the handler is good. `descend`: induction on the fuel in `depthRun`. Nothing in the RAM turns a
complex value into an integer, so this is the whole proof.

**Corollary (Lean, `zeta_mem_of_DFTProgram`).** If `DFTProgram order solve W` holds, then for every n ≥ 2,
ζ_n ∈ Q(ζ_d) with d = `run order n`. (Run `solve` on the indicator of index 1 with K = Q(ζ_d) and V = K·1; output
entry 1 is ζ_n.)

**Consequences used in the NOTE** [proved from P1 + the statement's syntax]:
1. No program can use a constant outside Q(ζ_d(n)): a unit whose coefficients are not in that field cannot be run as
   it is. Since subfields of cyclotomic fields are abelian over Q, an algebraic number whose Galois closure is
   non-abelian (for example 2^(1/3)) is never available, for any n, and no transcendental number is.
2. Control flow never depends on data or scalars: no atom maps paint `c _` to `w`, and `ifz`, `loop`, `tab`, `sow`,
   `descend` take their counts from `w`. So for each n the program is one straight-line K-linear program in the data
   (when `allow = false`), i.e. an arithmetic circuit generated by the fixed program from n.

## P2. One program for all n; finite non-input information [proved, from the statement's syntax]

`DFTGoal := ∃ order solve W, DFTProgram order solve W ∧ TimeBounds W`, and `DFTProgram order solve W` is
`∃ cBound, ∀ n, 0 < n → …`. So `order` and `solve` are fixed elements of the inductive type `Code` (finite trees),
chosen before n. The only data a `Code` term carries besides its shape are natural-number literals (`Atom.lit n`);
there is no complex literal (`Atom` has no constructor for one). Hence:
- the program may behave differently for each n only through computation from n (and is charged for it, including the
  integer high-water mark `peak ≤ (n+2)^cBound`);
- a family of units indexed by n and chosen non-constructively (one `Classical.choose` per n) cannot be embedded,
  since a function N -> units that the RAM cannot compute is not a finite tree; a FIXED unit (finitely many choices) can,
  and so can any fixed member of an asymptotic family;
- the proof itself may be classical: `DFTGoal` is a `Prop`, and the comparator permits `Classical.choice`. Upstream's
  own construction already works this way: `Able`/`Can` (`ProgramBounds.lean:30-41`) are
  `∃ (f : Code …) (C d : ℕ), ∀ i, …`, so the final program is never written out, only proved to exist.

## P4. Linear descent [proved; standard; not in Lean]

Let F ⊆ L be fields, A an F-matrix, b an F-vector. If Ay = b has a solution over L, it has one over F.
*Proof.* Solvable over a field iff rank A = rank [A | b]. Rank is the size of the largest nonzero minor, and minors of
an F-matrix are the same elements whether computed in F or L. ∎

## P5. Open-set solvability gives a rational unit [proved; not in Lean]

Let A(x), b(x) have entries in F[x_1..x_s], F = Q (or Q(i)), and let U be a nonempty open subset of R^s (of C^s when
F = Q(i)). Suppose A(x) y = b(x) is solvable in y for every x in U. Then there are x in F^s and y with entries in F with
A(x) y = b(x).
*Proof.* Let r be the largest rank of A(x) on U, reached at x0, with an r×r minor Δ(x0) ≠ 0. On the nonempty open set
U' = U ∩ {Δ ≠ 0}, rank A = r, and solvability forces every (r+1)×(r+1) minor of [A | b] to vanish there. A polynomial
vanishing on a nonempty open set is zero (it vanishes on a product grid of more than deg points per coordinate inside a box
in U'; Schwartz-Zippel, Mathlib `MvPolynomial.schwartz_zippel_totalDegree`), so those minors vanish identically. Δ is a
nonzero polynomial over F, so some x in F^s has Δ(x) ≠ 0 (F infinite; Mathlib `MvPolynomial.funext`). At that x,
rank A(x) ≥ r ≥ rank \[A | b\](x) ≥ rank A(x): solvable over L, hence over F by P4. ∎

**Why it applies to our units** [argued]. The unit condition "GLiveKernel for every f" is the formal-sum identity
(`the archive's checks/wht35/wider/w-engine.md` 3.1, re-read in `wave16/d-tof-cert/LEGIT.md` (c)): for each class of proportional letter
products, the sum of the path coefficients equals the target's. A path through the word picks ONE entry of each
`localM` matrix, so every such equation is multilinear in the mixing layers, with coefficients in Q(i) (in fact Z[1/2, i]). Fixing all
layers but one leaves a linear system for that layer with coefficients in Q(i)[other layers]; split real and imaginary
parts for rational unknowns. So P5 says: if the last layer can be re-solved after every small REAL perturbation of the
other layers, a rational unit (legitimate for the engine as it is) exists.
