letter is any element of B·dir·B, K = dir e_1 ⋯ dir e_m, 𝒩 = Paulis·scalars (normal in G, inside B, the kernel of

## 0. Two step models (this matters below)

- **Canonical engine** (`../../moonshot/theory-guide/RULES.md` §0, `hb.py`): a mix is a *scalar* combination of
  registers (old values), `c_r := Σ_s μ_s c_s`; a free letter is a separate step on one register. sl-alg's model
  (gates in GL_W(C), free steps on single rows) is the same thing.
- **Ledger mixes** (`../../slack/sl-combinatorics/ledger.py`, also the o3 words): `c_r := Σ μ_s b_s c_s` where the
  same source register may appear several times with different free letters. Such a mix multiplies a register by
  an element of the group algebra C[B] in one step. The canonical engine realises it only with a scratch register
  (it must hold c_s and b·c_s at once). A ledger mix in which every source register appears at most once is
  canonical without scratch (apply b to c_s in place, mix, undo b).

With unlimited scratch the two models have the same units and the same costs.

**The true model.** G is the group of matrices generated by the letters; a scalar matrix produced by letters (for
example XZXZ = −I) is a group element, acting as (−1)^f on f columns, not the number −1 (v-slack §1). ledger.py
normalises group elements modulo {1, i, −1, −i} and folds the phase into the coefficient. That is not the every-f
model: `t_scalar.py` → `t_scalar.out` gives a word that ledger.py accepts as a unit and the true model rejects
(x + (−I)·x + D₁x reads as D₁x). Every unit named in this file was re-checked in the true model (`checks.out`,
"true every-f model: True"), where each term carries its own power of i.
- fp-build's Lemma 1.2 and Proposition 1.3 (`../../packing/fp-build/PROOF.md`) [read] make this precise: the central
  idempotents e_k = ¼ Σ_j i^(−jk)[i^j] split C[G] into four blocks (f ≡ k mod 4), and ledger.py's convention is
  block 1. A word is a unit iff it is right in every block; ledger.py checks block 1 only.
- The augmentation used in Theorem C (§3) is non-zero only on block 0 (ε(e_k) = [k ≡ 0]), where the scalar
  matrices act as 1 and C[G]e_0 is the ordinary group algebra of G modulo scalars. So Theorem C's bound already
  holds for any word that is right at the column counts f ≡ 0 (mod 4); every unit is.

## 1. The module game: an exact reformulation of units with scratch

**Lemma M** [proved]. Fix W and m. Write contents as row vectors in C[G]^W (entry l = the coefficient of input l).
The least M of a unit with any number of scratch registers equals the least number of steps

  V ← V + C[B]·p·v     (v ∈ V, p a paid letter)

that lead from V_0 = C[B]^W (left C[B]-module) to a module containing K e_1, …, K e_W. The same holds if both sides
are restricted to moving single-term vectors only (every entry 0 or one term c·g).

*Proof.* (unit → module) Let V_t be the left C[B]-module generated by every content held by any register up to step
t, inputs included. A free letter or a mix writes an element of V_t, so V does not grow. A paid move on a register
holding v ∈ V_t writes p·v, so V_{t+1} = V_t + C[B]·p·v. At the end the delivering registers hold u·K e_l ∈ V.
(module → unit) Keep every vector ever produced in its own scratch register (copies are free). An element
Σ_i y_i v_i of V (y_i ∈ C[B]) is written in one canonical mix: first copy each needed b·v_i into its own scratch
register (copy, then a free letter in place), then one scalar mix over those registers. No intermediate content has
more terms than the v_i themselves, so the single-term restriction is respected. Then apply p (one paid move). At
the end write K e_l into the delivering registers. ∎

- In this language Theorem 5 (sl-alg) is the statement that each K e_l ∈ V_M has an expansion with a history of
  length ≥ m for input l; Theorem 4.3 (sl-comb) is the statement that if every moved v is frame-coherent in one
  fixed gauge, then M ≥ 2m for W = 2.
- **Proposition 6 for W = 2, restated:** in the module game for two inputs, reaching K e_1 and K e_2 needs 2m steps.
  This is the open two-array conjecture of the moonshot list; nothing below proves it in general.

## 2. Two registers, no scratch, single-label entries

**Theorem A** [proved]. Let a unit have exactly two registers (no scratch), canonical steps (or ledger mixes in which
no source register repeats), and suppose that at every moment every non-zero entry A_{rl} has all its terms in one
coset 𝒩·g_{rl} (one label per entry; Pauli twins such as (1 + iZ)·g are allowed). Then M ≥ 2m, at every block.

This contains sl-alg's Corollary 2′ (single-term entries) and the scratch-free case of sl-comb's sub-class (S2)
(Pauli-blind twins), and, unlike Theorem 4.3, it allows a different gauge in every joint episode.

*Proof.*
1. **Every step is invertible.** The state is a 2×2 matrix over C[G]; the end state D·K is invertible, and a
   product of square matrices over a finite-dimensional algebra is invertible only if every factor is. So no row
   is ever zero, and when neither row holds both inputs, the two rows hold different inputs (*separate period*).
   Otherwise some row holds both (*joint episode*).
2. **One relative label per episode.** For a row holding both inputs put ρ_r = ḡ_{r1}⁻¹ ḡ_{r2} ∈ Sp(2m,2). Moves
   and free letters multiply the row on the left, h·𝒩g = 𝒩·hg, so ρ_r is unchanged. A mix or gate writes rows
   α R_1 + β R_2 with scalar α, β. If both summands hold input l with different cosets, the new entry has support
   in two cosets (different cosets are disjoint sets of group elements, nothing cancels), which the hypothesis
   forbids. So the summands agree on every input they share. Hence a new row holding both inputs inherits ρ from a
   summand that held both; if no summand held both (rows (A, 0) and (0, B)), the step opens an episode with
   ρ = Ā⁻¹B̄. Inside an episode some row always holds both, so every later both-row inherits the same ρ.
3. **Positions inside an episode.** Give input 1 its raw positions ḡ⁻¹L0 and input 2 the twisted positions
   ρ·ḡ⁻¹L0. A both-row then has one position: ρ·ḡ_{r2}⁻¹L0 = ρρ⁻¹ḡ_{r1}⁻¹L0 = ḡ_{r1}⁻¹L0. Every row has one
   position; a paid move moves it by exactly one step (ρ·ḡ⁻¹ is an isometry and h̄⁻¹L0 is a neighbour of L0); free
   letters do not move it. Every non-monomial mix or gate in the episode joins rows that share an input, hence (by
   2) rows at a common position. The opening step is also at a common position: π(A) = Ā⁻¹L0 and
   ρB̄⁻¹L0 = Ā⁻¹B̄B̄⁻¹L0 = Ā⁻¹L0. The closing step (the mix after which no row holds both) joins rows that share an
   input, so it is at a common position too.
4. **Counting.** So both rows start the episode at one position P and end it at one position Q, and each row walks
   from P to Q one step per paid move: the episode costs ≥ 2·d(P, Q). Input 1 travels raw distance d(P, Q) across
   the episode; input 2 travels raw distance d(ρ⁻¹P, ρ⁻¹Q) = d(P, Q). In a separate period each input sits in one
   row and travels at most one step per move on that row. Summing over periods and episodes and using the
   triangle inequality from L0 to L_T for each input, M ≥ m + m. ∎

**Caveat on the step model** [computed, `checks.py` → `checks.out`]. Step 2 fails for ledger mixes with a repeated
source, because terms of one summand can cancel terms of another. The order-3 control word C6O3 of o3-build, written
exactly as in sl-comb's `t_known.py` with **two registers**, is an exact unit (M = 6 = 2m at block 3) whose stored
contents are single-term at every moment, while the two registers hold x0 + x1 (relative label 1) and x0 − s x1
(relative label s̄ ≠ 1) at the same time: holonomy without any same-input split. Its mixes
`c1 := c0 − c1 − s c1` and the six-summand readout repeat the source register. So:
- Corollary 2′ (and Theorem A) are theorems about canonical words, or ledger words without repeated sources.
- A two-register ledger word with repeated sources is, in the canonical engine, a word with one scratch register.
  For such words "one term per input" does **not** force a same-input split; they fall under §4 below.
- Consequence for the slack NOTE's search filter ("drop skeletons with one term per input"): it is valid for
  canonical two-register skeletons only; any search that writes two-register words with ledger mixes and repeated
  sources must not use it.

## 3. Height-homogeneous units save nothing (any W, any scratch, any contents)

A **height system** is a choice, for each input l, of a function h_l: Γ_m → Z with |h_l(x) − h_l(x')| ≤ 1 for
neighbours, h_l(L0) = 0 and h_l(L_T) = m. Examples: h_l = d(L0, ·) (the level); h_l = m − d(·, L_T); h_l = H∘φ_l
for a gauge φ_l and one function H. The height of a term g of input l is h_l(λ(g)), λ(g) = ḡ⁻¹L0 its position.

**Theorem C** [proved]. Let a unit have W inputs, any number of scratch registers and any contents. Suppose there is
a height system such that after every paid move the moved register's content has all its terms (over all inputs)
at one height. Then M ≥ W·m; in fact at least W·m paid moves land on heights 1, …, m with a new direction.

**Theorem C, quantitative form** [proved, same proof]. Drop the condition h_l(L_T) = m: let h_l be any integer
1-Lipschitz functions with h_l(L0) = 0 making every move output homogeneous. Then M ≥ Σ_l max(0, h_l(L_T)).
(The chain gives e_l ∈ E_k for 1 ≤ k ≤ h_l(L_T), so dim E_k ≥ #{l : h_l(L_T) ≥ k}.)

*Proof.* Use Lemma M: V_t is the left C[B]-module generated by C[B]^W and the outputs w_j = p_j·v_j of the paid
moves. Grade C[G]^W by height: an element is homogeneous of degree k if every term (l, g) has h_l(λ(g)) = k. Left
multiplication by B keeps positions (λ(bg) = λ(g)), so each C[B]·w_j is homogeneous, C[B]^W has degree 0, and
V = ⊕_k V^(k) is graded. Let ε: C[G]^W → C^W apply the augmentation (sum of coefficients) to each entry. It is
linear and ε(y·w) = ε(y)·ε(w) for y ∈ C[B], so E_k := ε(V^(k)) is spanned by the ε(w_j) of degree k (and
E_0 = C^W). A group element has augmentation 1, so ε(p·v) = ε(v).
- **Chain.** E_k ⊆ E_{k−1} for every k ≥ 1, at all times. True at the start. A move with output w = p·v of degree
  k′: write v = Σ_k v^(k) (homogeneous parts lie in V). p is injective on G and moves each position by one step, so
  the parts p·v^(k) have disjoint supports at heights k−1, k, k+1; since w has the single degree k′, v^(k) = 0
  unless |k − k′| ≤ 1. Hence ε(w) ∈ E_{k′−1} + E_{k′} + E_{k′+1} ⊆ E_{k′−1} (chain, k′ ≥ 1), and adding it to E_{k′}
  keeps the chain. For k′ ≤ 0 nothing at degrees ≥ 1 changes, and E_0 = C^W throughout.
- **Count.** Each move enlarges one E_{k′} by at most one dimension. At the end each delivering register holds
  u·K e_l, homogeneous of degree h_l(L_T) = m, so e_l ∈ E_m for all l and dim E_m = W; by the chain dim E_k = W for
  k = 1, …, m. So at least Σ_{k=1}^{m} dim E_k = W·m moves enlarged some E_k with k ≥ 1. ∎

The augmentation is multiplicative only in the true model (§0); with ledger.py's phase-folded coefficients the
chain can fail, and a first random test that used them did fail. In the true model the three claims of the proof
(ε(w) ∈ E_{k′−1}; the chain; Σ dim E_k ≤ moves) held on about 4,600 homogeneous moves at blocks 2 and 3 with two
and three inputs [computed, `t_chain.py` → `t_chain.out`, three seeds, no failure].

**Corollaries.**
- (C-a) *Every saver mixes heights.* For every height system, some paid move of a saving unit leaves a register
  whose terms sit at two different heights. With h_l = level: some move outputs a register holding terms at two
  different raw levels (two terms of one input, or terms of two inputs). With h_l = m − d(·, L_T): two terms at
  different distances from L_T. Frame packing, holonomy and same-input splits are all harmless as long as the moved
  terms stay at one height.
- (C-b) This contains sl-comb's Corollary 4.4 (a) (units without frame packing in one gauge whose sources coincide,
  or whose sinks coincide; dead moves deleted first, as there): take h_l = H∘φ_l with H = d(S, ·) (common source S)
  or H = m − d(·, T) (common sink T).
- (C-c) Two inputs, single-term moved registers, free twists (g₁⁻¹g₂ ∈ B): the two terms have equal level before
  and after every move (ℓ(p g₁ b) = ℓ(p g₁)), so Theorem C with h = level applies: this is Theorem B of §4. Twists in
  K⁻¹BK: the same with h = m − d(·, L_T).
- (C-d) Any W: units whose moved registers have all terms in one left coset g·B (right factors free; any number of
  terms per input, any holonomy) save nothing. The order-3 controls C6O3, C8O3 and the three-array HOLO3 of §6 are
  of this kind, and they cost exactly W·m (`checks.out`: "Theorem C hypothesis ... True").
- (C-e) As a search filter: a word for which some height system makes every move output homogeneous cannot save.
  Deciding this is exact and polynomial [proved; implemented, `heightfilter.py` → `heightfilter.out`]: a
  1-Lipschitz integer function on a subset of Γ_m extends to all of Γ_m iff |h(x) − h(y)| ≤ d(x, y) on the subset
  (take h(z) = min_x h(x) + d(x, z)), so the conditions are difference constraints — equalities inside each move
  output, |h_l(x) − h_l(y)| ≤ d(x, y) for each input, h_l(L0) = 0, h_l(L_T) = m — and Bellman–Ford decides them.
  Calibration: plain, HOLO3, C6O3 → a height system exists; gauge exchange → none.
- (C-f) *Theorem C is the general form of "no crossing slack, no saving".* For a common-frame design with sources
  a_s and sinks a*_s (sl-alg Theorem 1), a height system of the form h_s = H∘(gauge of s) exists iff every source
  is opposite every sink, d(a_s, a*_t) = m for all s, t [proved: H(x) = min_s d(a_s, x) works; conversely
  H(a_s) = 0, H(a*_t) = m and 1-Lipschitz force d ≥ m]. That is exactly the case of zero crossing overlaps. So for
  every unit, coherent or not, saving requires height mixing, the incoherent analogue of a source lying closer than
  m to another input's sink. This answers the slack round's question in one direction: some form of crossing is
  necessary for every saving (it does not say crossing is the only mechanism).

**Proposition D (clean cuts; the common root of Theorem C and sl-comb Lemma 4.2)** [proved]. Let Q = (Q_1, …, Q_W)
with Q_l ⊆ Γ_m. Call Q *clean* for a unit if no paid move output has a term of some input l at a position in Q_l
and a term of some input l′ at a position outside Q_{l′}. A move *crosses Q inward* if its output lies in Q while
the moved content had a term outside. If Q is clean, the number of inward crossings is at least
#{l : L_T ∈ Q_l, L0 ∉ Q_l}, and likewise outward. *Proof.* As in Theorem C with two degrees, "in" and "out": V
splits as V_in ⊕ V_out; ε(V_in) grows only at inward crossings, by at most one dimension each, starts as
span{e_l : L0 ∈ Q_l} and ends containing e_l for every l with L_T ∈ Q_l. ∎
- Theorem C is the case of the m concentric clean cuts {h ≥ k}, k = 1, …, m, each entered by all W inputs: a move
  whose output has height k′ can cross only {h ≥ k′} inward (its input has heights ≥ k′ − 1), so the inward
  demands add up to W·m. sl-comb Lemma 4.2 (frame-coherent moves in one gauge) is the case where
  every cut of gauge positions is clean; Hu's theorem then finishes Theorem 4.3 for W ≤ 2.
- So every unit obeys M ≥ max Σ y_{Q,d}·(inputs crossing Q in direction d) over y ≥ 0 on its clean cuts and the
  two directions, with Σ y_{Q,d} ≤ 1 over the (Q, d) that move j crosses, for every move j. A saver must
  therefore straddle enough cuts to destroy every such packing; straddling a cut is the precise meaning of
  "packing across it".

- (C-h) *The best bound of this kind for a given word is computable* [proved; `heightfilter.py` best_bound]. The
  pointwise-largest solution of a system of difference constraints is the vector of shortest-path distances from
  the zero node, so max Σ_l h_l(L_T) is a sum of shortest-path distances. Calibration (`heightfilter.out`): plain,
  HOLO3, C6O3 give W·m; the gauge-exchange unit gives 2m − 1 (it costs 2m).
- (C-i) *Quotient bound.* If a subgroup H ≤ Sp(2m,2) is such that every move output has all its terms in one
  H-orbit of positions (for example H generated by all twists of moved two-input registers, in the single-term
  case), then M ≥ W·d(H·L0, L_T): take h_l = d(H·L0, ·), which is H-invariant. So a unit can save at most
  W·(m − d(H·L0, L_T)) moves: the saving is capped by how close the twist group brings the raw frame to the
  transformed frame. This is the incoherent counterpart of the anatomy's "line labels give M ≥ W(m − 1)".

- (C-g) Theorem C is not a Theorem-R certificate: it needs the hypothesis, and without it Σ_k dim E_k is not
  defined (V is not graded). It is a structural theorem of the same kind as Theorem 4.3, and incomparable with it:
  4.3 allows any source/sink layout in one gauge but no frame packing; C allows frame packing at one height but
  needs one height system for all sources and sinks.

## 4. Two inputs, any scratch, single-term contents

By Lemma M this is the module game in which only single-term vectors are moved. A single-term vector is a
**single** (one input, position x) or a **pair** (c₁g₁, c₂g₂): input 1 at x = ḡ₁⁻¹L0, input 2 at y = ḡ₂⁻¹L0, twist
σ = ḡ₂⁻¹ḡ₁ ∈ Sp(2m,2), so y = σx. Left multiplication by B keeps (x, y, σ); a paid move sends x to any neighbour
x' and y to σx'; the twist and the coefficient ratio c₂/c₁ never change under moves. (Example: a pair with twist
σ = K̄ created at (x0, K̄x0) brings its second coordinate toward L0 while its first goes toward L_T; this is
crossing slack seen in the gauge of σ.)

**Lemma U (what the free closure can do)** [proved]. Let V contain pairs v = (g, c·h) and w with input 1 and input 2
at the same positions as v (twists may differ).
- (a) If c/c' (the ratio quotient) is not a root of unity, (g, 0) and (0, h) lie in V. *Proof:* translate w by an
  element of B so its first entry is exactly g: w ~ (g, c'·b₀h) with b₀ ∈ B. Then y·v + z·w = (g, 0) needs
  z(c'b₀ − c) = −c, and c'b₀ − c = c'(b₀ − c/c') is invertible in C[B] because b₀ has finite order and c/c' is not
  a root of unity (all eigenvalues of b₀ in the regular representation are roots of unity). ∎
- (b) A pair plus a single at one of its two positions gives the other single ("catalyst").
- (c) Pairs compose: if v = (g, h), w = (g', h) and u = (g', h') (exact elements) then a combination cancels the
  shared terms and leaves the pair (g, h') with twist σ_u σ_w⁻¹ σ_v. Any alternating path of pairs gives a
  composite pair, and composites can be moved like any vector.
- (d) A cycle of pairs whose ratio product is generic makes every position on it available (same computation).
- Pairs from one creation (copies of one lineage) have equal ratios, so a lineage meeting itself does nothing.

So the twist of a pair matters for where its moves lead, not for when it can be unpacked: unpacking needs a second
independent object at the same positions, or a cycle.

**Lemma G (all single-term vectors of V)** [proved]. Let V be spanned over C[B] by single-term generators. Form the
*cover graph* H: vertices (l, g) for l ∈ {1, 2}, g ∈ G; every B-translate of a single generator is a loop at its
vertex, every B-translate of a pair generator (c₁g₁, c₂g₂) is an edge (1, g₁)–(2, g₂) with that coefficient vector.
V is the C-span of these loop and edge vectors. Then:
- e_u = (unit vector at vertex u) lies in V iff the connected component of u in H contains a loop or a cycle whose
  coefficient product is non-degenerate. (Standard: the edge vectors of a tree component span a space of dimension
  |vertices| − 1 that contains no vertex vector; a loop or a non-degenerate cycle adds the missing dimension.)
  Copies of one lineage carry the same coefficient vector, so a cycle made only of one lineage's edges is
  degenerate. Call a component *unlocked* if it has a loop or a cycle with edges of two or more lineages
  (permissive: this over-approximates, which is the safe direction for lower bounds).
- A single-term pair e_u + c·e_w lies in V iff u and w are in one component (then c is forced by a path: a
  *composite*, Lemma U(c)), or both components are unlocked (then c is free: a *created* pair).
So the moves available to a single-term unit are: move an available single; move an edge; move a composite;
move a created pair. A lineage is a moved vector together with all its later moved copies; a composite of edges of
one lineage has that lineage's coefficient vector, a composite of two or more lineages starts a new lineage.

**Theorem B (free twists)** [proved]. Let a unit have two inputs and any number of scratch registers. Suppose every
paid move acts on a register whose content has at most one term per input (other contents are unrestricted), and
that whenever the moved register holds both inputs, c₁g₁x₁ + c₂g₂x₂, the twist is free: g₁⁻¹g₂ ∈ B. Then M ≥ 2m.

This contains the order-3 controls with scratch (twists 1 and s, both free) and every two-register ledger word of
that kind; it is not contained in Theorem 4.3 (two different twists give holonomy) nor in Corollary 2′ (scratch).

*Proof.* This is Corollary C-c of Theorem C. A second, direct proof on the cover graph H (kept because its
invariants are the starting point for general twists): with free twists every component of H lies at one level;
with L_l the largest level of an available single of input l, the three statements (C0) M ≥ L₁ + L₂,
(C1) M ≥ L₁ + ℓ(E) and M ≥ ℓ(E) + L₂ for every moved pair E, (C2) M ≥ ℓ(P) + ℓ(Q) for moved pairs of different
lineages, hold at the start and survive every move (singles, edges, composites, created pairs) and every unlocking
(by a loop or by a cycle of two lineages); at the end L₁ = L₂ = m. ∎

**Theorem B′ (any invariant height)** [proved]. Let f: Γ_m → Z satisfy |f(x) − f(x')| ≤ 1 for neighbours,
f(L0) = 0 and f(L_T) = m. If every moved two-input register has a twist σ with f∘σ = f (the other hypotheses as
in Theorem B), then M ≥ 2m. *Proof:* the two terms of every moved register then sit at one f-height before and
after the move; apply Theorem C with h₁ = h₂ = f. ∎
- f = d(L0, ·): twists fixing L0, i.e. g₁⁻¹g₂ ∈ B (Theorem B).
- f = m − d(·, L_T): twists fixing L_T, i.e. g₁⁻¹g₂ ∈ K⁻¹BK ("free relative to the transformed frame").
- The two cases cannot be mixed by this proof: a word whose packed moves use some twists fixing only L0 and others
  fixing only L_T is not covered.

*Where the direct proof uses the hypothesis.* Only in "every component lies at one level". With general twists an edge
joins levels a and b ≠ a, the closure releases singles at many levels at once, and (C0)–(C2) are no longer
enough: a composite of two lineages A, B whose path starts and ends on edges of lineage A needs a cross bound
ℓ₁(P) + ℓ₂(R) ≤ M between two branches P, R of the same lineage, which is false in general (two branches of one
lineage share their prefix). So the general case (Conjecture T below) needs a finer invariant.

**Corollary T₀ (no holonomy crossing, no saving)** [proved, from Theorem C]. Let 𝒯 ⊂ Sp(2m,2) be the twists of all
moved pairs (y = σx), and let 𝒢 be the groupoid they generate on the two inputs (σ: input 1 → input 2, σ⁻¹ back,
and all composites, e.g. σ₃σ₂⁻¹σ₁, the twists of Lemma U(c)). If d(τL0, L_T) = m for every τ ∈ 𝒢 (identities
included), then M ≥ 2m. *Proof.* Let O_l be the set of images of L0 in input-l coordinates under the morphisms of 𝒢
ending at l (both inputs start at L0), and h_l = d(O_l, ·). Then h_l is 1-Lipschitz, h_l(L0) = 0, h_l(L_T) = m by
the hypothesis, and h₂(σx) = d(σ⁻¹O₂, x) = d(O₁, x) = h₁(x) for every σ ∈ 𝒯, so every moved pair is homogeneous;
Theorem C applies. ∎
- Free twists (σL0 = L0) and twists fixing L_T satisfy the hypothesis (Theorems B, B′); one twist σ satisfies it iff
  σ⁻¹L0 and σL0 are opposite L_T, i.e. iff there is no crossing overlap (sl-alg Theorem 1).
- **So a single-term two-input saver needs a holonomy crossing:** a composite of the twists it moves that carries the
  raw frame to within distance < m of the transformed frame. With one twist this is ordinary crossing slack, which
  Theorem 4.3 already excludes for two inputs; so a saver needs at least two twists whose composite crosses. The
  frame-graph cut argument fails on exactly this configuration: gluing each moved pair's two positions creates the
  path L0 → σ⁻¹L0 ⇝ ρ⁻¹L_T → L_T of length < m for input 2 when d(σ⁻¹L0, ρ⁻¹L_T) < m.

**What else is proved for this class.**
- (P1) If one gauge makes every moved pair coherent (all moved pairs, composites included, have the same twist),
  then M ≥ 2m: this is Theorem 4.3 applied to the word of Lemma M [proved there; it allows any free closure].
- (P2) Let L be one lineage (a pair created once, with all its moved copies). Suppose L enters the free closure
  only through catalyst unpacking of input 2 (Lemma U(b) with an input-1 catalyst): never in a composite, a cycle,
  or a two-pair unpacking. Then replacing every move of L by the same move of a single holding input 2 alone, along
  L's input-2 coordinates, gives a word of equal cost that releases the same singles [proved: the replacing single
  sits exactly at every position where L released input 2]. Hence a cheapest counterexample to M ≥ 2m in this class
  contains, after all such replacements, moved pairs of at least two different twists (otherwise P1 applies;
  composites of pairs with one twist σ again have twist σσ⁻¹σ = σ).
- (P3) Blocks 2 and 3 are settled by Theorem R (2W and 14W/5 round up to 2m; Lean-checked for any scratch)
  [read: `../../proofs/NOTE.md` line 45]. So the class is open from block 4 on, exactly where 2 in 7 lives.

**Rigidity is essential** [proved]. In the relaxation where a pair move may move its two coordinates along any two
edges (no fixed twist), two inputs reach L_T in 3m/2 moves for even m: move a pair from (L0, L0) j = m/2 steps up
on both coordinates; branch A takes input 1 up to L_T while input 2 walks back to L0 (unpack input 1 with the free
catalyst at L0); branch B takes input 1 back to L0 while input 2 goes up to L_T (unpack with the free catalyst at
L0); total 3j. With a fixed twist σ this is impossible: branch A forces σ(L_T) = L0 = σ(L0). So any proof of
M ≥ 2m in this class must use that between compositions a pair's twist is a fixed isometry of Γ_m.
- Nor can a proof keep track of which input each move carries and look for two move-disjoint walks: already in a
  branching play with one fixed twist (prefix shared, input 1 unpacked on one branch with a catalyst of input 2,
  input 2 unpacked on the other with a catalyst made from the first output) no two move-disjoint walks exist, while
  the count M ≥ lv₁ + lv₂ holds [argued, by hand]. Theorem 4.3 survives this because Hu's flow may route either
  input along any move of the frame graph; with two or more twists there is no single graph in which to do that.

**Conjecture T (the single-term two-input bound).** In the single-term module game, at every moment
max lv(available input-1 position) + max lv(available input-2 position) ≤ M.
- It is equivalent to "M ≥ 2m for single-term two-input units with scratch" [proved]: finish plainly from positions
  x, y at levels a, b (each lies on a geodesic from L0 to some point opposite L0, at distance m − a, m − b), and
  pre-multiply each input by a free letter so that both end points become L_T; this gives a unit with
  M + (m − a) + (m − b) moves.
- True at blocks 2 and 3 (Theorem R through the equivalence), for one twist (P1), and at block 2 for the restricted
  game up to 3 moves (computed). Open from block 4.
- A proof would extend Corollary 2′ to any scratch: a two-input saver must then hold two terms of one input in one

## 5. "A change of basis makes every unit common-frame" is false

**Proposition S** [proved; exact unit computed, `checks.py` SPLIT1]. There are exact units that are not frame-coherent
after any change of input basis y = F x with F ∈ GL_W(C[R]), R the free letters commuting with K (the changes that
keep the target K covariant, as in o3-build Lemma 1), and in any gauge.

*Example (W = 1, any m ≥ 1).* Registers c (holds x), t, s. t := c; s := c; move s by dir e_1; c := c + s, so
c = (1 + D₁)x; move c by dir e_1, so c = (D₁ + X₁)x (D₁² = X^{e_1} is free); c := c − X₁t, so c = D₁x; then
dir e_2 … dir e_m on c. Exact unit, M = m + 1 (`checks.out`: unit = True, M = 3 at block 2, 4 at block 3; "frame
packing forced"). *Why no basis change helps:* for W = 1, F is a unit f of C[R] ⊂ C[B]. In the new basis the
moved content is (1 + D₁)·f⁻¹. The terms of f⁻¹ lie in B (frame L0), those of D₁f⁻¹ lie in D₁B (frame λ(D₁)
moved by elements of B fixing L0, never L0 itself since D₁B ∩ B = ∅), and both parts are non-zero. So the moved
register always carries one input at two frames, in every gauge (a gauge moves all frames by one isometry). ∎

- The example wastes a move, so it does not touch Proposition 6's cost form. It shows that Proposition 6 cannot be
  proved by structure alone ("every unit is common-frame after a basis change"); a proof has to transform units
  while not increasing M.
- The positive side of the brief's hint is real but narrow: C8O3 / C6O3 become the plain schedule in y = (x₁ + x₂,
  x₁ − s x₂). That works because their only packing is a holonomy between two inputs, removable by a basis change
  with coefficients in C[⟨s⟩]; a same-input split at two frames (as in SPLIT1) is not removable.

## 6. Three arrays

**Proposition H3** [proved; computed `checks.py` HOLO3]. The episode lemma fails for three registers even in the
canonical engine with no scratch. Word: R0 := R0 + R1; free s on R1; R1 := R1 + R2; R2 := R2 + R0 (contents
x0 + x1, s x1 + x2, x0 + x1 + x2); K on all three (3m moves); R2 := R2 − R0; R1 := R1 − R2; free s on R1;
R0 := R0 − R1. With s the swap of two coordinates (commutes with K, s² = 1) this is an exact unit at blocks 2 and 3
with M = 3m, single-term contents at every moment, canonical steps (no repeated sources), and holonomy (relative
label of inputs 1, 2 is s̄ in R1 and 1 in R2), so no gauge is frame-coherent (`checks.out`).
- So any W = 3 version of Corollary 2′ must handle holonomy, as W = 2 must with scratch (§4). Proposition 6 for
  W = 3 contains the W = 3 common-frame question (a 3-session undirected coding-gain question on Γ_m), which cut
  arguments cannot decide (sl-comb Remark 4.6) and which nc-gain is bounding. What is proved for W = 3 (and any W) is
  Theorem C: height-homogeneous units, holonomy and multi-term contents included, cost ≥ W·m; HOLO3 is such a unit.

## 7. Where this leaves Proposition 6

- **Proved for every W:** a unit for which some height system makes every move output homogeneous costs ≥ W·m
  (Theorem C). So Proposition 6 holds in that class, which contains the packing units checked here (C6O3, HOLO3;
  C8O3 has the same free-twist structure), Pauli twins (1 + Z^v)·g, and sl-comb's Corollary 4.4 (a).
- **Proved for W = 2 in addition:** M ≥ 2m whenever (i) one gauge has no frame packing (Theorem 4.3, any scratch),
  or (ii) two registers, canonical steps, one label per entry with a new gauge per episode (Theorem A).
- **Open for W = 2:** units that, for every height system, have a move output at two heights and frame packing in
  every gauge; in particular single-term contents with scratch and non-free twists (§4, Conjecture T).
- **Refuted:** the structural strengthening (Proposition S).
- **For p6-refute / fp-build (necessary conditions on any two-array saver):**
  1. frame packing in every gauge (Theorem 4.3);
  2. for EVERY height system, some paid move whose output register holds terms at two different heights; first
     tests: two different raw levels, and two different distances from L_T (Theorem C);
  3. with two registers and canonical steps: an entry with two labels at some moment (Theorem A);
  4. if no moved register ever holds two terms of one input: a moved two-input register whose two group elements
     differ by a paid (non-free) right factor (Theorem B, a case of 2);
  5. in the same case: a holonomy crossing, i.e. a composite of the moved twists carrying L0 closer than m to L_T
     (Corollary T₀), which needs at least two twists (Theorem 4.3).
  Searches written with ledger mixes that repeat sources are effectively using scratch (§0); for them condition 3
  and the slack NOTE's "one term per input" filter do not apply, but 1, 2 and 4 do.
