## 0. Setting

As in fp-build PROOF.md section 0 and Lemma 1.1 [read; checked by v-fp-build]. G is the group generated by the engine
letters (scalars exactly {1, i, -1, -i}); N = Paulis times scalars is normal in G and lies in the free group B;
`G/N = Sp(2m,2)`, `B/N = P` (the preimage of P is B). `g -> gbar` is the action on Pauli labels by conjugation,
`g P g^-1`. `dir z = (1+i)/2 1 + (1-i)/2 X^z` maps to `T_z`, K to `Kbar`. `pi : C[G] -> C[G/N] = C[Sp]` is the
quotient map (it is the frame-game image of fp-build Theorem 2.2, left inclusion).

`s = i.1` is a central free letter and `e_k = (1/4) sum_j i^(-jk) [s^j]` (k mod 4) are central idempotents of C[G]
lying in C[B]; at f columns `e_k` acts as 1 iff f = k (mod 4) (fp-build Lemma 1.2) [read]. "Right at every f" is a
formal identity in C[G] (theory-guide RULES section 0) [read].

Notation: `P_u = X^a Z^b` for a label u = (a|b) (scalar-free Pauli, real matrix); `Pexp(M)` = the element
`sum_u m_u [P_u]` of C[N] where `M = sum_u m_u P_u`; `omega` the symplectic form on labels.

*Frame-game program* (fp-build Definition 2.1, module form): states `u_0^(l) = [1] e_l` (inputs); for t = 1..M,
`v_t = sum_(s<t) beta_(t,s) u_s` with `beta in C[P]`, and `u_t = T_(z_t) v_t`; outputs
`sum_s gamma_(l,s) u_s = c_l Kbar e_l` with `gamma in C[P]`, `c_l != 0`.

## 1. The even blocks: realisations with one copy of every character

**Lemma 1 (the Pauli algebra in the even blocks)** [proved].
For k = 0 and k = 2, `[-1] e_k = [s]^2 e_k = i^(2k) e_k = e_k`, so `[P_u][P_u'] e_k = [P_(u+u')] e_k` and
`C[N] e_k` is the group algebra of F_2^(2m). Its primitive idempotents are

    e^k_w = 4^-m sum_u (-1)^omega(w,u) [P_u] e_k,   w in F_2^(2m),

with `[i^j P_u] e^k_w = i^(jk) (-1)^omega(w,u) e^k_w =: chi^k_w(i^j P_u) e^k_w`. Conjugation permutes them:
`[g] e^k_w [g]^-1 = e^k_(g.w)` where `g.chi = chi(g^-1 . g)`; on labels `g.w = gbar w` for k = 0 and
`g.w = gbar w + t_g` (an affine action) for k = 2.

**Lemma 2 (realisations)** [proved; computed at blocks 2-5].
- Block 0: G acts on `End(V) = C^(n x n)` by `R_0(g) M = g M g^-1`. Then `R_0(n) P_w = chi^0_w(n) P_w` for n in N
  (Paulis commute or anticommute; scalars cancel). Since `R_0(g) P_w` is an eigenvector for the character
  `g.chi^0_w`, whose eigenspace is the line through `P_(g.w)`,

      g P_w g^-1 = d_0(g, w) P_(g.w),   d_0(g, w) in mu_4.

- Block 2: G acts on `V (x) V = C^(n x n)` (this is the f = 2 action) by `R_2(g) M = g M g^T`. For n = i^j P_u,
  `n P_w n^T = i^(2j) (-1)^omega(u,w) P_w = chi^2_w(n) P_w`, because `P_u P_w P_u^T = (-1)^omega(u,w) P_w`. So

      g P_w g^T = d_2(g, w) P_(g.w),   d_2(g, w) in mu_4.

- In both cases R_k is a representation, so `d_k(gh, w) = d_k(g, h.w) d_k(h, w)` (cocycle), and
  `d_k(gn, w) = d_k(g, w) chi^k_w(n)` for n in N.

[computed, `t_hom.py`, `out_hom_m2.txt`, `out_hom_m3.txt`: the character orbits generated by the letters are
{1, 4^m - 1} in block 0 and {N-, N+} = {6, 10} (m = 2), {28, 36} (m = 3) in block 2; 80 of 80 random cocycle identities
and all 4 x 4^m Pauli rules hold.]

*Remark 1 (Remark 1.5's cocycle question is closed)* [proved, given standard Clifford theory [cited: Clifford-Mackey]].
Each realisation contains every character of its block exactly once, so the stabiliser `G_w` of `chi_w` acts on the
line `C P_w` by the linear character `d_k(., w)`, which extends `chi^k_w`. Hence the cocycles are trivial and

    C[G] e_0 = C[Sp]  (+)  M_(4^m - 1)(C[Sp_v]),       C[G] e_2 = M_(N+)(C[O+(2m,2)])  (+)  M_(N-)(C[O-(2m,2)]),

with `N+- = 2^(m-1)(2^m +- 1)`, untwisted. The summand C[Sp] of block 0 (the trivial character, w = 0) is the frame
game itself. Nothing below depends on this remark.

## 2. The lift

**Theorem 1 (a homomorphic section of the frame-game quotient)** [proved; computed at blocks 2, 3 and 4]. For every
block m there is a unital algebra homomorphism `Lambda : C[Sp(2m,2)] -> C[G]` with

  (a) `pi o Lambda = id`;
  (b) `Lambda(gbar) = [g] D(g)` with `D(g)` in C[N] for every g in G; in particular `Lambda(C[P])` lies in C[B];
  (c) `Lambda(T_z) = [dir z] D(dir z)` with the six-term free element

          D(dir z) = c_z (e_1 + e_2) + cbar_z (e_0 + e_3),   c_z = ((1-i)[1] + (1+i)[X^z]) / 2,  cbar_z = ((1+i)[1] + (1-i)[X^z]) / 2;

  (d) `Lambda(Kbar) = [K] D(K)` with `D(K)` a unit of C[N].

*Construction.* `D(g) = sum_k d_k(g) e_k` with

    d_0(g) = sum_w d_0(g, w)^-1 e^0_w,     d_2(g) = sum_w d_2(g, w)^-1 e^2_w,
    d_1(g) = Pexp(g^-1) e_1,                d_3(g) = Pexp(conj(g)^-1) e_3 = Pexp(g^T) e_3,

and `Lambda(lambda) = [g] D(g)` for any g with `gbar = lambda`, extended linearly.

*Proof.* It suffices to show that each `Lambda_k(lambda) = [g] d_k(g)` is well defined (independent of the lift g),
multiplicative, and `Lambda_k(1) = e_k`; then `Lambda = sum_k Lambda_k` is a unital homomorphism because the e_k are
orthogonal central idempotents summing to 1.

- k = 1 and k = 3: `Lambda_1 = Phi_1^-1 (1 (x) .)` with the isomorphism `Phi_1(g) = g (x) gbar` of
  `C[G] e_1` onto `M_n (x) C[Sp]` (fp-build Proposition 1.3, checked by v-fp-build), since
  `Phi_1([g] Pexp(g^-1)) = (g (x) gbar)(g^-1 (x) 1) = 1 (x) gbar`. Likewise `Lambda_3 = Phi_3^-1(1 (x) .)` with
  `Phi_3(g) = conj(g) (x) gbar` (v-fp-build PROOF section 1), using the real basis `P_u`. Both are homomorphisms
  because they are inverse images of the homomorphism `lambda -> 1 (x) lambda`.
- k = 0, 2 (write d, chi, e_w for d_k, chi^k, e^k_w).
  - *Independent of the lift:* for n in N, `[gn] d(gn) = [g][n] sum_w d(g,w)^-1 chi_w(n)^-1 e_w`
    `= [g] sum_w chi_w(n) d(g,w)^-1 chi_w(n)^-1 e_w = [g] d(g)` (Lemma 1: `[n] e_w = chi_w(n) e_w`; Lemma 2).
  - *Multiplicative:* `[g] d(g) [h] d(h) = [gh] ([h]^-1 d(g) [h]) d(h)`, and `[h]^-1 e_w [h] = e_(h^-1 . w)`, so
    `[h]^-1 d(g) [h] d(h) = sum_u d(g, h.u)^-1 d(h, u)^-1 e_u = sum_u d(gh, u)^-1 e_u = d(gh)` by the cocycle rule.
  - *Unit:* `d(1) = sum_w e_w = e_k`.
- (a) pi sends `[s]` to 1, so `pi(e_k) = 1` for k = 0 and 0 otherwise; pi sends every `[P_u]` to 1, so
  `pi(e^0_w) = 4^-m sum_u (-1)^omega(w,u) = 1` if w = 0 and 0 otherwise; and `d_0(g, 0) = 1` (g 1 g^-1 = 1). Hence
  `pi(Lambda(gbar)) = gbar`.
- (b) is the construction; for p in P choose g in B (B maps onto P).
- (c) Block 0: `dir z` commutes with `P_w` when `z.b_w = 0`; when `z.b_w = 1`,
  `dir z P_w dir z^-1 = i P_w X^z = -i P_(w + (z|0))`. So `d_0(dir z, w) = 1` or `-i` according to `z.b_w`, and
  `sum_(z.b_w = 0) e^0_w = ([1] + [X^z]) e_0 / 2`, giving `d_0 = cbar_z e_0`. Block 2: `dir z^T = dir z`,
  `dir z^2 = X^z`; if `z.b_w = 0`, `dir z P_w dir z = X^z P_w = P_(w + (z|0))` (d_2 = 1); if `z.b_w = 1`,
  `dir z P_w dir z = P_w (a - bX^z)(a + bX^z) = (a^2 - b^2) P_w = i P_w` with a = (1+i)/2, b = (1-i)/2 (d_2 = i). So
  `d_2 = c_z e_2`. Block 1: `Pexp(dir z^-1) = c_z` (e3-rmbuild Lemma R; fp-build Theorem 2.2). Block 3:
  `Pexp(dir z^T) = Pexp(dir z) = cbar_z`.
- (d) In the even blocks `d_k(K)^-1 = sum_w d_k(K, w) e_w`; in the odd blocks `Pexp` is an algebra isomorphism of
  `M_n` onto `C[N] e_k` (Phi_k restricted to C[N] e_k), so `d_k(K)^-1 = Pexp(K) e_1`, resp. `Pexp(conj K) e_3`. []

**Corollary 2 (completion: the frame game is the whole problem)** [proved]. Every frame-game program at block m,
W inputs, M paid moves `T_(z_1), ..., T_(z_M)`, gives an engine word with the same W, the same paid letters
`[dir z_1], ..., [dir z_M]` in the same order and on the same data flow, that is right at every number of digit
columns f. Together with the left inclusion of fp-build Theorem 2.2:

    engine units  =  frame-game programs        (same W, same M, same paid moves),

up to the format of the free steps (Remark 3).

*Proof.* Apply Lambda to the program. Set `u'_0^(l) = [1] e_l`, `v'_t = sum_s D(dir z_t) Lambda(beta_(t,s)) u'_s`
(a free step: its coefficients lie in C[B] by (b), (c)), `u'_t = [dir z_t] v'_t` (one paid letter). By induction
`u'_t = Lambda(u_t)` (Lambda is a homomorphism, `Lambda(1) = 1`, and `Lambda(T_z) v = [dir z] D(dir z) v`). The
outputs: `sum_s Lambda(gamma_(l,s)) u'_s = c_l Lambda(Kbar) e_l = c_l [K] D(K) e_l`, so the free element
`c_l^-1 [K] D(K)^-1 [K]^-1` (in C[N], since N is normal and D(K) is a unit of C[N]) applied on the left gives
`[K] e_l`. This is a formal identity in C[G], i.e. right at every f. []

*Remark 3 (format; what does not transfer)* [proved].
- The free steps of the lifted word are multi-term elements of C[B]: `D(dir z)` (six group elements), `Lambda(p) =
  [phat] D(phat)`, and the final correction. In the engine's step format (scalar mixes, one free letter per term) a
  multi-term free factor on one register needs one scratch register to accumulate into. Units allow scratch
  (RULES section 0: "scratch may end as garbage"). So the equality above is for units with scratch; results stated
  for two arrays WITHOUT scratch (sl-algebra Corollary 2'; fp-capacity Proposition D) do not transfer through this
  lift, exactly as v-fp-build noted for fp-build's f = 1 lift.
- Corrections can be merged along a run of paid moves on one register whose intermediate states are not read by any
  other step: `Lambda(T_(z_k) ... T_(z_1)) = [dir z_k ... dir z_1] D(dir z_k ... dir z_1)`. Then the correction goes
  into the free step before the run (or a new one, if the run starts at an input). For the plain schedule the
  corrections cancel: `Q [K] D(K) = [K]`, so dropping both gives back the plain schedule. (`lift.py` does not merge;
  it inserts D(dir z) before every move, so every lifted state is exactly Lambda of the frame state.)
- Sizes [computed, `out_dsize.txt`]: `D(g)` has 6 group elements for `dir z`, 8 for a phase letter
  `diag(i^((z.x + c) mod 2))` with z != 0, 1 for a shift and for a scalar, 8 for an elementary address map
  `x_i += x_j`, and up to `2 . 4^m` for a general address map (all of it in the odd blocks; it is fp-build's
  `Pexp(phat^-1)`; the even blocks need 1 term for any address map). Lifting letter by letter, with address maps
  written as products of elementary ones, every correction has at most 8 terms, at every block.

**Corollary 4 (transfer of theorems)** [proved from Corollary 2 and the sandwich].
- Every exclusion proved for engine units holds in the frame game, and conversely. For example Theorem 2W (no 2 in 3
  at block 2), which fp-build used for the frame game only as a "consistency check, not shown for the frame game", now
  holds there. (The other direction, frame-game exclusions are engine exclusions, was already known.)
- A frame-game program found and checked exactly (fpa.end_solve plus verify_combo, over Q) IS an engine unit, with an
  explicit lift (`lift.py`). The raw-array replay at f = 1..8 then checks the lifting code, not the existence.
- A certificate for any engine word: if its frame image (every free coefficient beta replaced by pi(beta) in C[P],
  `[dir z]` by `T_z`) delivers `Kbar e_l`, then `Lambda` of that image is an engine unit with the word's paid moves,
  whatever the word's own coefficients do at even f. (The converse fails: a word can have a unit's moves and wrong
  coefficients.)
- What is NOT implied: an identity in `ledger.py`'s convention is block 1 only (fp-build Remark 1.4); a word right in
  block 1 need not have a frame image that is right for the same skeleton (only the lane version, fp-build Remark 2.4,
  is known). So the warning about ledger-style checks stands; the fix is to check in the frame game instead.

*Remark 5 (why this was the only possible obstruction)* [argued]. Lemma 1.2 makes the four blocks independent, and
blocks 1 and 3 were already automatic (fp-build, v-fp-build). The even blocks could have blocked completion only if
some character's stabiliser carried a nontrivial cocycle (then the orbit's component would be a twisted group algebra
of O+-(2m,2) or Sp_v, into which C[Sp] need not map compatibly) or if the phase mismatch between the letters and the
coset action were not free. Remark 1 shows the cocycles are trivial (the realisations End(V) and V (x) V carry every
character once), and the mismatch is diagonal in the characters, i.e. an element of the commutative free algebra
C[N] e_k.
