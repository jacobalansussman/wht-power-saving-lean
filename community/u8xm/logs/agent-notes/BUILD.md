## 1. The construction

- **The word.** This is the hub's U8 word (Jeremy Kothe #869/#870, Chafik Boukhalfa #890, Capalbo #942, on Kothe's
  #799 lineage). k-word reproduced it on the Colab with the hub's own `reproduce_barch.py`; the canonical sha256 is
  `24db880b...` and matches the hub's pin.
- **Exit frames, as in candidate (A) (k-lower).** 126 helpers end at exit frames of dimension 4 or 8 instead of the
  full frame. The hub's 171 tail gates are lowered as the last gates of phase B.
- **Mutable sources (x-mutable).** Shea's 112 source copies are folded back into their sources, so phases A and B
  write the sources and x-mutable's derived end gate `g8z Mti` restores them. Exception: the 5 copies of the
  sources that host a split centre (sources 9, 11, 57, 81 and 92) are kept, because the scatter reads retained
  totals only from slots (x-mutable's rule E2). R = 504 + 5 = 509 slots.
- **Histogram.** {1:2553, 2:338, 3:446, 4:162, 5:72, 8:13}, N = 5679. This is the hub profile plus the 5 copies.
- **Bank table.** The pad-minimal table from s-stack and k-word: 3,771 banks, one pad of 27, W = 10939.

## 2. What is new in Lean (Work/KMX, k-combine, 13 Oct 2026)

1. **`HalvesZ.lean`.** x-exit-lean's `GLabX` / `GLabX.inv`, word for word, over x-mutable's scalar half `GScalZ`,
   which has no `hx`. The end gate to split is `g8z Mti` (x and slot rows of the inverse) and the backward one is
   `(h8z Mt)ᵀ`. The rest gate may touch x roles: they stand at the old frame of the full label, as x-mutable showed.
   The result is the same package `XEX.GInvX`. The module is generated by checked text substitution
   (`tools/make_engine.py`).
2. **`ExitEndZ.lean`.** It proves `exit_hGrZ` and `exit_hHrZ`: x-mutable's end gates never touch an exit helper.
   This needs three finite conditions on the total matrix `Mt`. Two are k-lower's (`ExitRows` and `ExitCols`). The
   third is new: **`ExitColsX`**, no x row of `Mt` reads an exit helper. With the other two it is equivalent to
   x-mutable's condition (d) on `Mti`, which k-word checked on the U8 word.
3. **`ZCheckZ.lean`.** It defines `zCheckZ` and `zCheckZ_sound`, k-lower's zero check with x-mutable's replay
   `gItemsZ` (kinds okAZK and okBZK). It is generated by text substitution.
4. **`LabelsXZ.lean`.** It defines `ValidX.glabXZ`, `glabXZ_ranks` and `glabXZ_res`: k-lower's exit label half
   over `GScalZ`. It is generated by text substitution.
5. **`GlueXZ.lean`.** Its pieces:
   - `exit_of_zchecksZ`: the three exit conditions from zero checks. The rows of the exit batches are the x
     registers together with the slots.
   - `exit_of_twinZ`: the conditions carry over from k-lower's y-free twin.
   - `glabXOfZ`, `ginvXOfZ`, `ginvXOfZ_cost` and `ginvXOfZ_res`.

All five modules compiled on the Mac, one at a time through locked.sh (about 6 GB each). Their axioms are
`[propext, Classical.choice, Quot.sound]` and there is no sorry. The logs are in `logs/lean/`.

## 4. Build

```sh
. /content/work/env.sh
mkdir -p /content/work/B && tar xzf k-combine-u8xm.tar.gz -C /content/work/B && cd /content/work/B/k-combine-u8xm
sha256sum -c --quiet SHA256SUMS && echo PACKAGE-OK
cp -a /content/work/c-xexit /content/work/B-tree        # or a copy of /content/work/k-lower; never the base itself
T=/content/work/B-tree/lean/complex588
bash scripts/setup.sh $PWD $T                          # PATCH_LAKEFILE=1 on a plain Shea tree (then lake build XExit.*)
tmux -L B new -d -s B "bash scripts/build-direct.sh $PWD $T /content/work/logs/B > /content/work/logs/B.out 2>&1; \
  bash scripts/checks.sh U8XM $T /content/work/logs/B > /content/work/logs/B-checks.out 2>&1"
```

**The Lake route, which k-combine's run used.** It is faster when the official comparator follows: Lake writes its
traces, so the comparator's own `lake build` inside the jail has nothing to rebuild. After `setup.sh`, wait until
fewer than 2 heavy Lean processes are running, then run:
```sh
cd $T && LEAN_NUM_THREADS=1 lake build Work.FourierU8XM.Main Work.FourierU8XM.UniformFourierChallenge \
  Work.FourierU8XMNeg.UniformFourierChallenge Work.GCert.Data.U8XMControls Work.FourierU8XM.Axioms
```
`LEAN_NUM_THREADS=1` makes Lake run one job at a time. The script for this route is
`/content/work/logs/k-combine/run2.sh` (a copy is in k-combine/colab/run2.sh). It builds, runs the checks of
section 5, runs `lake build --no-build`, and then runs `cmp.sh`.

To fail fast, the only new kernel checks are `Gen.U8XMScal0..3`, `Gen.U8XMYChk`, `Gen.U8XMEChk`, `Gen.U8XMZChk0..5`,
`Gen.U8XMZOK` and the label checks.

## 6. Exact Python preflights (all PASS; `out/PREFLIGHT-U8XM.json`)

1. **Certificate** (`tools/make_cert.py`). The input is k-lower's U8X certificate (sha256 `62fbff5c...`). The copies
   are folded back by k-word's `partial_uncopy`, copied verbatim, keeping the 5 centre-source copies. The histogram,
   N and cst come from m-gen's own frame replay. The exit-route invoice identity holds: 6087 = 6087.
2. **Exit conditions on the exact rational total matrix.** ExitRows, ExitCols and ExitColsX all hold, with no
   violator. The identity y ← x holds and the y columns are unit. 107 x rows are not unit rows, as expected with
   mutable sources.
3. **Scalar audit** (m-gen's `scalar_audit_z`). Shea's rule gives SPar (10, 22, 8, 16, 8).
4. **Exact packed mirror** (m-gen's `zmirror`).
   - `scalCheckZ` ×4, `yCheckZ` and `eCheckZ` ×3 are all true at SPar (10, 22, 8, 16, 8) and E7 (10, 8, 8, 16, 8).
   - At sw 21 all four scalar batches fail, so the digit width is tight.
5. **Zero-check design** (`tools/zdesignZ.py`, an exact mirror of `GS.zCheckZ`). It has 42 batches:
   - 14 bit batches over the 125 light exits (7 bits);
   - 1 heavy batch (exit 587);
   - 27 chunks.
   The bit and heavy batches use rows x + slots. Every batch passes at (10, 36, 32, 32, 1).
6. **Label side.** Sussman's gxgen/gxcore mirror, run through Shea's driver with k-lower's exit-aware patch (E1x,
   E6x) and m-gen's mutable kinds, accepts the certificate.
7. **Round trip.** The generated `S0.lean`, parsed back, equals the certificate. On the parsed text every scalar,
   E7 and zero-check kernel term evaluates to true.
8. **Price** (`make_sched_x.py`). Shea's `validate` and the exact `GX.schedK` mirror accept the table; the
   duplicate-owner and wrong-pad controls are false. Shea's `exact_moment` brackets the root in
   [0.001386887487202, 0.001386887487203]. Sussman's `plan_block` (B = 10, s = 40) gives kernel 13868857 and DFT 13868856.
